# Shotlist security audit — 2026-09-01 (Claude)

## Verified sound
- **Components**: only `MainActivity` exported (launcher + ACTION_SEND, both required).
  Receivers, FileProvider: `exported=false`; provider grants are per-share URI only.
- **PendingIntents**: 5/5 use `FLAG_IMMUTABLE`.
- **Network**: `INTERNET` + `ACCESS_NETWORK_STATE` stripped at manifest merge —
  the app process holds no network socket permission. This does NOT preclude IPC,
  content intents, or user-initiated file shares crossing process boundaries;
  the Play-services IPC caveat stays documented in the store doc.
- **Backup**: `allowBackup=false` + full exclusion rules incl. device-transfer.
- **SQL**: Room parameterized throughout; FTS input sanitized (alphanumeric tokens,
  6-term cap, prefix-only).
- **Vault**: WIFI/CODE auto-vault at classification; mixed-vault shots excluded from
  memories at the engine AND pixels blocked feed-side; biometric relocks on stop;
  vault widget exposes count only. Moment-loop notifies EVENT/DEADLINE only — secrets
  never reach notifications.
- **Signing**: committed key is DEBUG-only by design (documented); release key TBD
  private at store day.

## Hardened this pass
- Notifications (reminders, moment loop, digest) now `VISIBILITY_PRIVATE`: content is
  redacted on locked screens when the user hides sensitive notifications.
